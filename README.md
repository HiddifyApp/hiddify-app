This is a personal build of the open-source Hiddify client. It keeps this fork's branding and release links while syncing compatible changes from the upstream app. It is an independent distribution and is not published to the official app stores.

## Install

- **Android:** Open the downloaded APK and allow installation if prompted.
- **Windows:** Extract the Portable ZIP and run `Hiddify.exe`. This personal build is unsigned; Windows may show a security warning.
- **macOS:** Open the DMG and move Hiddify to Applications.
- **Linux:** Make the AppImage executable and run it. Debian users can install the DEB package.

After installation, add your subscription and tap **Connect**.

## Updates

GitHub Actions checks upstream app and core releases every six hours. Compatible upstream changes are merged into this fork and built with this fork's release branding. Merge conflicts stop the sync for review instead of overwriting personal changes. Releases are published directly here without opening pull requests.

## Upstream
